# Implementation

## Overview

Staged, rung-by-rung implementation ladders for proposals a maintainer has
already accepted. Sits between [`../Proposal/`](../Proposal/README.md)'s
*unsettled* and [`../Foundational/`](../Foundational/README.md)'s *settled*.

## Index

_Empty._ No proposal has been accepted, so no ladder exists. When the first
one is accepted, its staging file is created here in the same change that
moves its settled content into `Foundational/`.

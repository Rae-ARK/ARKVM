# ARKVM

This is repo root readme and stays minimal by design. It shouldn't go stale ever

In a word this is the runtime that will guarantee ARKlight-Ecosystem/ARKlight will remain pixel perfect no matter what target backend it is. it is the in between .arklight (binary ir) and target backend's native code (Flutter's skia equivalent)
